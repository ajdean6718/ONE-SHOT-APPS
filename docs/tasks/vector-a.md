Owned: `extensions/seam_studio/vector/{canvas,shapes,style,arrange,tools}.py`, `vector/props.py` (add fields only), `tests/integration/test_vector_{canvas,shapes,style,arrange,tools}.py`.
`canvas.py` already has a working foundation API (see its docstring) used by other workers: keep those functions and signatures stable; extend freely.

Implement:
- canvas.py: operators `seam.canvas_new` (ensure canvas, frame it), `seam.artboard_add`, `seam.artboard_set_active`, artboard resize via `obj.seam.artboard` props (an "artboard" producer regenerates the plane mesh and its background material), `seam.view_artboard` (2D views: top ortho, centered/fit on active artboard; no-op message in background). Layers: `seam.layer_add/remove/move/set_active`, visibility/lock via native collection flags, SEAM_UL layer list. Adoption hook (`engine.add_update_hook`): new CURVE/FONT objects that land in a SEAM layer get role, id, canvas parent (preserving world matrix) and a z slot.
- shapes.py: `seam.add_shape(kind, width, height, radius, sides, inner_ratio, x, y)` via `seam_core.shapes.from_kind` (being implemented by core-geometry in parallel; until merged, tests needing it may skip with reason "core pending") + `canvas.new_shape_object`. `ShapeProducer(kind="shape", priority=10)`: while `shape.kind != NONE`, params own geometry → regenerate curve; if the curve was edited by hand (curve signature ≠ last generated), set kind NONE ("expanded"). `seam.shape_expand`.
- style.py: `MaterialProducer` ("material", priority 20): per SHAPE/TEXT object a material "SEAM ‹name›" synced from style: Emission (flat) mixed with Transparent by alpha×opacity (`compat.set_material_blend_alpha`), viewport display colour = fill colour (Solid MATERIAL mode); `GradientProducer` ("gradient", priority 25) bakes linear/radial gradients into a small image used by the material (object-space mapping over the shape bbox) and set as active node (Solid TEXTURE mode); `StrokeProducer` ("stroke", priority 30): child mesh object role STROKE (hide_select, parent = owner, identity inverse, local z = +Z_STEP*0.5) from `seam_core.stroke.stroke_mesh` over flattened local paths, its own material; removed when stroke disabled; heals missing/duplicated/orphaned children. Panel "Appearance" (fill/stroke/gradient stops/opacity/fill rule) for SHAPE and TEXT.
- arrange.py: `seam.arrange(mode)` front/forward/backward/back within the layer (z slots), `seam.group`/`seam.ungroup` (Empty role GROUP under the canvas; world matrices preserved exactly), `seam.align(mode, relative_to=SELECTION|ARTBOARD|ACTIVE)` using canvas-space bounds of the evaluated geometry, `seam.distribute(axis, by=CENTERS|SPACING)`, panel "Transform" with artboard-relative X / Y (Y down) / W / H / rotation editable values (apply to object transform), guides `seam.guide_add(orientation, position)` (role GUIDE thin object, unselectable in render) and `seam.guides_clear`.
- tools.py: WorkSpaceTools (VIEW_3D, OBJECT mode) `seam.tool_rect`, `_rrect`, `_ellipse`, `_polygon`, `_star`, `_line`, `_artboard`, bound to a modal `seam.draw_shape` (mouse → canvas plane via `region_2d_to_location_3d` onto the canvas plane; Shift = square, Alt = from center; live preview by updating params) that also supports an `exec` path with explicit canvas coordinates (used by tests). Skip tool registration gracefully in background mode. Tool keymaps only.
