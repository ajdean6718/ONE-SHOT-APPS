# Task: paint (raster documents, layers, masks, selections, PNG I/O)

Owned: `extensions/seam_studio/paint/*` (props: add fields only), `tests/integration/test_paint_*.py`.
Architecture D4: native Texture Paint on a canvas plane whose material composites SEAM layers (8-bit sRGB images) with Mix nodes; masks are images; selections drive the native stencil mask; export composites with numpy (`seam_core.raster`, being implemented in parallel by core-raster-io — until merged, tests needing it skip with "kernel pending").

Implement:
- rasterdoc.py (public API used by others): `new_raster_doc(scene, name, width, height, background="TRANSPARENT", x=None, y=None) -> doc`, `get_doc(scene, raster_id)`, `doc_for_object(obj)`, `add_layer(doc, name, index=None)`, `remove_layer`, `move_layer`, `duplicate_layer`, `merge_down`, `add_mask`, `apply_mask`, `remove_mask`, `layer_array(layer) / write_layer_array(layer, arr)` (linear float H×W×4 top-row-first ↔ 8-bit sRGB image), `composite_array(doc) -> H×W×4 linear float`, `build_material(doc)`, `set_paint_target(doc, layer_index, target)`. Images: 8-bit RGBA, `use_fake_user`, named "SEAM ‹doc› ‹layer›". Canvas object: plane mesh width×height px (UVs), role RASTER, `raster_id` set, placed at the active artboard top-left via `canvas.add_artwork_object`. Material: visible layers bottom→top, `compat.new_mix_rgb_node` per blend mode (`raster.BLENDER_MIX_TYPE`), factor = layer alpha × opacity × mask, alpha accumulation with Math nodes, Emission + Transparent, `compat.set_material_blend_alpha`. Rebuild material when layer structure/props change (a "rastermat" producer or direct rebuild in ops — your call, but undo must stay consistent). `RasterCacheProducer` ("rastercache", priority 60) keeps `doc.composite` up to date for Solid TEXTURE display and export; design how painting strokes are detected (e.g. image `is_dirty` + per-layer revision) and document it. `save_pre` handler (`@persistent`) packs dirty layer/mask/selection images.
- ops.py: `seam.raster_new`, `seam.raster_layer_add/remove/duplicate/move/merge_down`, `seam.raster_mask_add/apply/remove`, `seam.raster_set_paint_target(target=LAYER|MASK)`, `seam.raster_paint_mode` (select canvas, Texture Paint mode, image_paint.mode MATERIAL + active slot; in GUI also top ortho view on the canvas), `seam.raster_fill` (selection or layer, colour), `seam.raster_clear` (erase selection), `seam.raster_resize_canvas` optional.
- selection.py: `seam.raster_select_rect/ellipse/lasso` (pixel coordinates; modal versions may come later), `seam.raster_select_all/none/invert`, selection mask image wired to `tool_settings.image_paint` stencil (`use_stencil_layer`, `stencil_image`, `invert_stencil`) so native brushes paint only inside the selection; GUI-only selection outline overlay (skip in background).
- io.py: `seam.raster_import_png` (new layer from file; fit/center) and `seam.raster_export_png` (composite → `seam_core.png`), straight alpha, sRGB 8-bit.
- ui.py: Paint panels (document size/background, layers UIList with visibility/lock/opacity/blend/mask, selection, actions) in sidebar category "SEAM".
Tests (both runtimes): acceptance scenario 2 — create doc, two layers, write pixels via `write_layer_array` (native brush strokes are covered by the GUI suite), erase within a selection, opacity/blend/mask changes change `composite_array` exactly as `seam_core.raster.composite` predicts, undo/redo a layer property change (`bpy.ops.ed.undo_push/undo/redo`), save/reopen preserves pixels exactly (8-bit) and layer props, PNG export decodes to the expected pixels; material node tree contains one image node per layer + mask.
