REVOLVE via `seam_core.mesh.revolve` (written in parallel by core-geometry; until merged, skip REVOLVE tests when it raises NotImplementedError). Apply units_scale, orientation (UPRIGHT/FLAT per architecture §3), origin, mirrored-transform winding fix. EXTRUDE of open splines: ignore them with a message; self-intersecting/zero-area input → ERROR state with message, previous geometry kept (use `seam_core.geometry.validate_rings` when available, guard NotImplementedError). 4. `link/lifecycle.py` (engine update hook via `engine.add_update_hook`): deleted source → MISSING_SOURCE (target kept); deleted target → remove link record; duplicated objects with the same SEAM id → copy gets a new id; a duplicated RESULT that no link targets → role NONE + independent; undo restored a source whose pointer is None but `source_id` exists → re-point.
