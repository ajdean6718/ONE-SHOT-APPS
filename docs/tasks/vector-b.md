# Task: vector-b (typography, pathfinder, clipping, freehand, SVG/PNG export)

Owned: `extensions/seam_studio/vector/{text,pathfinder,clip,freehand,io_svg,export_png}.py`, `tests/integration/test_vector_{text,pathfinder,clip,freehand,io}.py`, `resources/fixtures/vector/`.
Depends on the canvas API (present in `vector/canvas.py`) and seam_core kernels being implemented in parallel by core-geometry (geometry, fitting, stroke, boolean2d) and core-raster-io (render2d, raster, png, svg). Code against the documented signatures; tests that need a kernel still raising NotImplementedError must `pytest.skip("kernel pending: <name>")` (the integrator re-runs them after merging). Style helpers (materials etc.) come from vector-a in parallel: read style values directly from `obj.seam.style`.

Implement:
- text.py: `seam.add_text(body, x, y, size)` → FONT object role TEXT via `canvas.add_artwork_object`; Typography panel (font list + `seam.font_load`, size, character/word/line spacing, align_x/align_y, bold/italic/underline/small caps for the edit-mode selection or whole body, text box width/height). `seam.text_to_outline`: creates a SHAPE curve (owner_id = text id) kept live by `OutlineProducer` ("outline", priority 5) from `bridge.text_paths`; the text object is hidden but kept (non-destructive); `seam.outline_expand` (stop following text) and `seam.outline_revert` (show text, delete outline).
- pathfinder.py: `seam.pathfinder(op=UNION|DIFFERENCE|INTERSECT|EXCLUDE, keep_originals=False, resolution=12)` over ≥2 selected SHAPEs in canvas space; DIFFERENCE = bottom-most minus the rest (Illustrator "Minus Front"); result is one compound SHAPE (VECTOR-handle polygon paths, holes as extra splines) with the bottom-most shape's style; actionable error report on invalid geometry. `seam.compound_make` / `seam.compound_release`.
- clip.py: `seam.clip_make` (top-most selected shape clips the others via `obj.seam.clip_source`), `seam.clip_release`; `ClipProducer` ("clip", priority 40) shows clipped geometry in the viewport as a derived CLIP_RESULT mesh child while the original stays editable (document the display approach). Export must honour clips (render2d clip, SVG clipPath).
- freehand.py: tool `seam.tool_pencil` + modal `seam.draw_freehand` (samples on the canvas plane, `fitting.smooth_polyline` + `fit_bezier` on release; closes when end ≈ start; stroke on, fill off) with an exec path taking explicit points. Tablet pressure → width is NOT supported: say so in the tool description.
- export_png.py: `collect_render_items(scene, artboard)` (FillItems with Solid/Linear/Radial paints in canvas coords, strokes via `stroke_outline` NONZERO, clips; ImageItems for RASTER objects via `paint.rasterdoc.composite_array(doc)` if available — guard ImportError/AttributeError) and `seam.png_export(filepath, artboard, scale, transparent)` → `render2d.render` → `raster.to_uint8_srgb` → `png.write_png`.
- io_svg.py: `seam.svg_export(filepath, text_mode)` (items in z-order; text as outlines by default) and `seam.svg_import(filepath)` (shapes + styles; artboard from viewBox; warnings reported via `self.report`). Add both to File > Import/Export menus.
Tests (both runtimes): acceptance scenario 1 — create shapes and text, edit a bezier node and typography (size/spacing), save/reopen, export SVG and PNG with no 3D objects present; PNG pixels at known points have expected colours; SVG re-import geometry matches; pathfinder areas; clip export; freehand exec path; outline live update when text changes.
